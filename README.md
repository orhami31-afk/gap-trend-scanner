# Gap & Trend Breakout - סורק ובוט מסחר

מערכת מודולרית לסריקת מניות למסחר סווינג קצר (2-5 ימים) לפי אסטרטגיית
Gap & Trend Breakout, בדיוק לפי המפרט שסופק.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `config.py` | כל הפרמטרים של האסטרטגיה - שנה כאן ערכים |
| `data_provider.py` | שליפת נתוני שוק (yfinance כברירת מחדל) |
| `indicators.py` | EMA, SMA, RSI, MACD, Volume Profile / POC |
| `trendline.py` | זיהוי קווי מגמה ופריצות |
| `universe.py` | שלב 1 - סינון יקום המניות (מחיר, נפח, RVOL, גאפ) |
| `sentiment_filter.py` | שלב 3 - פילטר סנטימנט שוק רחב (SPY/QQQ) |
| `entry_signals.py` | שלב 2+3 - הרכבת כל תנאי הכניסה יחד |
| `risk_manager.py` | שלב 4 - סטופ/יעד/גודל פוזיציה/גרירת breakeven |
| `trade_logger.py` | שלב 5 - לוגים מסודרים |
| `broker.py` | ממשק ביצוע - PaperBroker (סימולציה) ו-AlpacaBroker (שלד לחיבור אמיתי) |
| `scanner.py` | המנוע המרכזי שמחבר הכל |
| `main.py` | נקודת הכניסה להרצה |

## התקנה

```bash
pip install yfinance pandas numpy --break-system-packages
```

## הרצה (מצב סימולציה - בטוח, לא שולח פקודות אמיתיות)

```bash
python main.py
```

זה ירוץ עם `PaperBroker` שרק מדפיס ללוג מה היה קורה, בלי לגעת בכסף אמיתי.
תוצאות נשמרות גם לקובץ `gap_trend_bot.log`.

## מעבר למסחר חי

1. פתח חשבון ב-Alpaca (או ברוקר אחר עם API).
2. `pip install alpaca-trade-api --break-system-packages`
3. ב-`main.py`, החלף:
   ```python
   broker = PaperBroker()
   ```
   ב:
   ```python
   from broker import AlpacaBroker
   broker = AlpacaBroker(api_key="...", secret_key="...", paper=True)  # תמיד תתחיל עם paper=True!
   ```
4. **מומלץ מאוד**: הרץ שבועות על `paper=True` (חשבון נייר של Alpaca עצמו,
   לא PaperBroker שלנו) לפני שעוברים לכסף אמיתי.

## חדש: סריקה יומית אוטומטית + אפליקציית תצוגה

- **`watchlist.py`** - יקום ברירת מחדל של כ-300 מניות נזילות. כדי להגיע ל-1000
  בדיוק, ראה הוראות בתוך הקובץ (העלאת `tickers.csv`).
- **`backtest.py`** - לכל מניה שעוברת את התנאים, מריץ בדיקה היסטורית על
  הנתונים של אותה מניה (setups דומים בעבר) ומחזיר אחוז הצלחה משוער +
  כמה פעמים זה קרה בעבר (sample_size). זה **לא** הבטחה - זה אומדן
  סטטיסטי מבוסס עבר, ומהימנותו תלויה בכמות הדגימות.
- **`history_tracker.py`** - שומר את תוצאות כל יום ל-`history/scan_<תאריך>.json`,
  ובכל הרצה בודק את ההמלצות הפתוחות מהעבר: האם המחיר הגיע ליעד (target_hit),
  לסטופ (stop_hit), עדיין פתוח (open), או עבר את חלון הזמן המקסימלי (expired).
- **`.github/workflows/daily_scan.yml`** - מריץ את `main.py` אוטומטית כל יום
  ב-22:30 שעון ישראל (בענן - לא תלוי שהמחשב שלך יהיה דלוק). ראה הערות
  בקובץ לגבי הגדרה חד-פעמית והתאמת שעון קיץ/חורף.
- **האפליקציה (`gap-trend-desk.html`)** - יש לה עכשיו לשונית "המלצות יומיות"
  (מייבאת ומציגה את קובץ ה-JSON היומי) ולשונית "היסטוריה" (כל הימים
  שיובאו בעבר, כולל צביעה האם כל המלצה פגעה ביעד/סטופ).

### חיבור ל-TradingView

חשוב להיות מדויקים: **אין ל-TradingView API ציבורי** שמאפשר לאפליקציה
חיצונית "להתחבר" לחשבון אישי ולמשוך נתונים על פי דרישה לסריקה של 1000
מניות. הדרך היחידה הרשמית היא Alerts שמוגדרים ידנית ב-Pine Script לכל
תנאי בנפרד ושולחים Webhook - לא מתאים לסריקה משולבת עם 6 תנאים. לכן
המערכת משתמשת ב-yfinance (מקור נתונים חינמי ואמין למחירים/נפח/אינדיקטורים
היסטוריים) - זו בפועל הדרך המעשית לסריקה אוטומטית רחבה כזו.

### זרימת העבודה היומית

1. כל יום ב-22:30 (או בהרצה ידנית) `main.py` רץ, סורק את היקום, שומר
   תוצאות ל-`history/scan_<תאריך>.json`, ומעדכן תוצאות של המלצות ישנות.
2. פותחים את הקובץ ב-GitHub, מעתיקים את התוכן.
3. מדביקים בלשונית "המלצות יומיות" באפליקציה -> מקבלים תמונה מרוכזת עם
   צבע ירוק/אדום עדין ללונג/שורט, כניסה/סטופ/יעד, זמן אחזקה מוצע (1-10
   ימים), ואחוז הצלחה משוער.
4. בלשונית "היסטוריה" - כל הימים הקודמים, וכל שורה מציגה האם היא פגעה
   ביעד, בסטופ, עדיין פתוחה, או פגה.

## מה עדיין דורש השלמה ידנית

- **מפתחות API** של הברוקר - לא כלולים מטעמי אבטחה, אתה צריך להזין בעצמך.
- **Bracket orders** ב-`AlpacaBroker.place_entry_order` - כרגע שולח רק
  פקודת כניסה; פקודות סטופ/יעד נלוות מסומנות ב-TODO וצריך להשלים לפי
  ה-API הספציפי של הברוקר שתבחר.
- **תדירות הרצה**: `run_daily_scan()` מיועד לרוץ פעם ביום (בפתיחת המסחר),
  ו-`monitor_open_positions()` מיועד לרוץ בלולאה כל כמה דקות. אתה צריך
  להוסיף scheduler (למשל `cron`, `APScheduler`, או לולאת `while True` עם
  `time.sleep`) בהתאם לצרכים שלך.
- **רשימת המניות לסריקה** (`WATCHLIST` ב-`main.py`) - הגדרתי רשימת דוגמה
  של מניות נזילות; מומלץ להתאים לפי מה שמעניין אותך (יכול גם להיות S&P
  500 מלא).

## הערה חשובה

זו מערכת שנבנתה **בדיוק לפי המפרט הטכני שהגדרת** - היא לא המלצת השקעה
ואינה מבטיחה רווח. מסחר אלגוריתמי אוטומטי כרוך בסיכון ממשי לכסף אמיתי.
מומלץ מאוד:
- להריץ תקופה ארוכה במצב `PaperBroker` / paper trading לפני כסף אמיתי.
- לבצע Backtesting היסטורי על הלוגיקה לפני הפעלה חיה (לא כלול כאן -
  אפשר לבקש בנפרד מודול backtesting שמריץ את אותה הלוגיקה על נתונים
  היסטוריים).
- לעקוב אחרי הבוט באופן שוטף ולא להשאיר אותו רץ ללא פיקוח.
